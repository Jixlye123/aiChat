# AI Chatbot

A powerful, intelligent AI chatbot called LeadBot Ai built with modern technologies to enhance user interaction. The chatbot uses natural language processing (NLP) and machine learning to respond to user queries, assist with tasks, and provide information across various domains.

## Features

- **Natural Language Processing (NLP):** Understands and processes user input in natural language.
- **Personalized Responses:** Tailors responses based on user interactions and preferences.
- **Multi-domain Support:** Capable of answering a wide range of topics.
- **JWT Authentication:** Secure login and user management using JWT tokens.
- **Email Handling:** Integrates Nodemailer for email notifications and user registration.
- **Interactive UI:** Easy-to-use frontend for seamless user interaction.

## Technologies Used

- **Frontend:** React, React Router, Material UI
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (for storing user data)
- **Authentication:** JWT (JSON Web Tokens)
